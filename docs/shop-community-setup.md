# 店舗への投稿機能（公開前の設定）

対象：あま市・紀美野町・朝霞市のPayPay、富田林市のPayPay商品券。
タイトル・URL・H1は変更しない。公開前投稿・訂正・通報は一般ユーザーへ返さない。

## 必須設定

0. `20260916_protect_admin_profiles.sql` で既存の `profiles` を保護する。
   一般利用者の書き込みを禁止し、ログイン済み本人に `id,is_admin` の読み取りだけを許可する。
1. 既存Supabaseプロジェクトで `supabase/migrations/20260915_shop_community.sql` を実行。
   新規テーブル2個とRPC2個のみ作成する。既存の店舗・応援・記事データは変更しない。
   続いて `tests/shop-community.integration.sql` で権限・公開制御・連投制限を確認する（テストデータはロールバック）。
2. Vercelのサーバー環境変数に `SUPABASE_SERVICE_ROLE_KEY` を設定。
   `NEXT_PUBLIC_`を付けない。チャット、Git、画面キャプチャにキーを残さない。
3. `/admin/login` から既存のSupabase Authユーザーでログインし、`profiles.is_admin` が管理者であることを確認。
   新たな管理者権限の付与が必要な場合は対象ユーザーを確認してから実施する。
4. プレビュー環境で `SHOP_COMMUNITY_ENABLED=true` を設定し、以下の動作を確認。
   プレビューではVercelが提供する `VERCEL_URL` / `VERCEL_BRANCH_URL` のオリジンも許可する。
   `NEXT_PUBLIC_SITE_URL` は本番URLを維持する。
5. 検証後に本番の `SHOP_COMMUNITY_ENABLED=true` を設定して再デプロイ。
   障害時は false にして再デプロイすれば従来の店舗一覧・応援ボタンに戻る。

## 公開前の実機確認

- 一般利用者の投稿が未確認として保存され、一般ページには表示されない。
- `/admin/community` は未ログイン・非管理者では操作できない。
- 管理者による公開後だけ本文が一般ページに表示され、非公開操作で消える。
- 訂正依頼・通報は公開できず、対応済み操作でも店舗マスタは自動変更されない。
- 通報対象の本文確認と非公開ができる。
- ログイン済み一般ユーザー・anonのREST/RPC直アクセスでは投稿テーブルを取得・操作できない。
- 同じ通信元の日替わりハッシュで11件目が拒否される（共有回線も合算）。
- スマホ、キーボード操作、送信失敗時の入力保持、応援からの任意投稿を確認。
- あま市のタイトル・H1・canonicalを変更前と比較する。

## 運用

管理画面で個人情報、宣伝、誹謗中傷、未確認の還元対象断定を確認して公開する。
訂正依頼は一次情報で確認してから店舗JSONなどを別途修正する。
投稿は開催回ごとに分離し、旧開催回の内容を次回に流用しない。
一般表示は店舗ごとの最新3件、ページ全体で最大1500件。60秒キャッシュで店舗単位のDB問い合わせを避ける。
投稿にはIPを保存しない。日替わりHMAC値のみ連投制限用テーブルに保存し、期限を過ぎた値は次回投稿時に削除する。
恒久的な匿名本人認証ではないため、投稿本人の断定はしない。削除依頼は管理者が確認し、まず非公開にする。

このテストは入力、API、認可の境界をモックで確認する。実DBのRLSと同時投稿時の制限、公開後の表示は別途必須。
